# MovieIQ 🎬

MovieIQ is a data-driven web application and dashboard that predicts movie success based on various key performance indicators.

## Features
* **Predictive Modeling:** Predicts outcomes using a loaded machine learning model.
* **Interactive Inputs:** Adjust parameters like Budget, Runtime, and Rating to see how they affect the prediction.
* **Dynamic Filtering:** Filter data by genres such as Action, Adventure, Animation, Comedy, and Drama.

## Tech Stack
* Python
* Streamlit
* Pandas / Scikit-Learn (adjust these based on your actual libraries)
